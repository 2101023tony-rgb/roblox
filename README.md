# ROBLOX CLUB MVP

## 실행
`index.html`을 브라우저에서 열면 됩니다.

## 포함 기능
- 닉네임 기반 로컬 데모 프로필
- 미션 목록과 로컬 활동 점수
- 게임 커뮤니티 게시글
- 안내/안전 공지

## 중요한 제한
이 버전은 프론트엔드 데모이며 데이터는 해당 기기의 브라우저에만 저장됩니다. 여러 사용자 간 동기화, 관리자 검수, 로그인 인증, 실제 광고/제휴 추적, 현금 또는 Robux 지급 기능은 없습니다. 포인트는 현금/Robux 가치가 없는 활동 점수입니다.

실서비스 전에는 서버·DB·개인정보 처리방침·신고/차단·미성년자 보호·광고주 계약 및 보상 허용 여부 검토가 필요합니다.
